# 🎯 Финальная архитектура сайтов DEO CRM

## ✅ **Проблема решена!**

**Была ошибка:**
```
Error: You cannot have two parallel pages that resolve to the same path.
Please check /(public)/page and /(studio)/page.
```

**Решение:**
- ❌ Удалены папки групп маршрутов `(studio)` и `(public)`
- ✅ Созданы обычные папки `/studio` и `/crm`
- ✅ Очищен кэш Next.js (удалена папка `.next`)

## 📁 **Текущая структура (рабочая)**

```
frontend/src/app/
├── studio/              ← Сайт студии DEO Core Codes
│   ├── layout.tsx      ← Apple дизайн-система
│   └── page.tsx        ← Главная страница (Apple стиль)
├── crm/                ← Публичный сайт DEO CRM
│   ├── layout.tsx      ← Бизнес дизайн
│   └── page.tsx        ← Главная страница (маркетинг)
├── (dashboard)/        ← Внутренняя CRM (существующая)
├── page.tsx           ← Корневой редирект → /crm
└── middleware.ts      ← Обработка маршрутов
```

## 🚀 **Как запустить (после фикса)**

```bash
# 1. Перейти в директорию frontend
cd frontend

# 2. Убедиться, что старые папки удалены
rm -rf .next "(public)" "(studio)"

# 3. Запустить сервер
npm run dev
```

## 🎨 **Дизайн-системы**

### 1. **Apple Design System** (`/studio`)
- **Цвета:** Action Blue (#0066cc), Parchment (#f5f5f7), Tiles (#272729)
- **Типографика:** SF Pro Display/Text (Inter для не-Apple)
- **Компоненты:** Кнопки, тайлы, навигация, карточки
- **Особенности:** Чередование светлых/тёмных секций, минимализм

### 2. **Public CRM Design** (`/crm`)
- **Цвета:** Брендовые цвета из существующей CRM
- **Стиль:** Бизнес-ориентированный, конверсионный
- **Особенности:** Чёткие CTA, маркетинговые секции

## 🔧 **Что было исправлено**

   - `(studio)` → создан `/studio`

2. **Созданы отдельные layout:**
