## 🔄 Middleware и защита роутов

```typescript
// middleware.ts — Логика защиты роутов

publicRoutes = ['/login', '/register', '/forgot-password', '/reset-password/*']
authRoutes = ['/login', '/register']        // Редирект на /dashboard если авторизован
clientRoutes = ['/cabinet/*']                // Только роль client
adminRoutes = ['/admin/*']                  // Только superadmin/owner
pmRoutes = ['/clients/*', '/leads/*']       // Manager+ роли
allStaffRoutes = ['/dashboard', '/tasks/*', '/projects/*', '/messenger/*']
```

### Правила редиректов

| Текущий путь | Роль | Результат |
|-------------|------|-----------|
| `/` | Любая | → `/dashboard` (или `/login` если не auth) |
| `/login` | Authenticated | → `/dashboard` |
| `/admin/*` | Не admin | → `/403` |
| `/cabinet/*` | Не client | → `/403` |
| `/clients/*` | developer/client | → `/403` |
