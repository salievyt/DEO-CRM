# 🧪 Тестирование сайтов DEO CRM

## 🚀 Быстрый старт для тестирования

### 1. Установка и запуск
```bash
# Перейти в директорию frontend
cd frontend

# Установить зависимости (если не установлены)
npm install

# Запустить в режиме разработки
npm run dev
```

### 2. Проверка сайтов

**Все сайты доступны на localhost:3000:**

| Сайт | Путь | Описание |
|------|------|----------|
| **Сайт студии** | `http://localhost:3000/studio` | DEO Core Codes (Apple дизайн) |
| **Публичный CRM** | `http://localhost:3000/crm` | Маркетинговый сайт DEO CRM |
| **Внутренняя CRM** | `http://localhost:3000/dashboard` | Существующее приложение CRM |

### 3. Проверка компонентов

#### Apple Design System (студия)
- ✅ Кнопки: `/studio` → кнопки "Смотреть проекты", "О студии"
- ✅ Тайлы: светлый/тёмный/пачмент секции
- ✅ Навигация: глобальный нав и суб-нав
- ✅ Карточки: сетка услуг

#### Public CRM
- ✅ Навигация: лого, ссылки, CTA кнопки
- ✅ Герой-секция: заголовок, описание, кнопки
- ✅ Функции: сетка из 6 карточек
- ✅ CTA секция: градиентный фон
- ✅ Футер: колонки ссылок

## 🔧 Исправление ошибок

### Если есть ошибки:

1. **Ошибка TypeScript**:
```bash
npm run typecheck
```

2. **Ошибка сборки**:
```bash
npm run build
```

3. **Ошибка линтера**:
```bash
npm run lint
```

### Возможные проблемы:

1. **Отсутствуют зависимости**:
```bash
npm install --save-dev @types/react @types/node
```

2. **Проблемы с путями**:
- Проверьте импорты в `studio/layout.tsx` и `crm/layout.tsx`
- Убедитесь, что `@/shared/...` пути работают

3. **Проблемы с Tailwind**:
```bash
# Проверить конфигурацию
npx tailwindcss --config tailwind.config.ts --content "src/**/*.{ts,tsx}" --output test.css
```

## 🔄 Если что-то не работает

1. **Очистить кэш Next.js**:
```bash
rm -rf .next
npm run dev
```

2. **Переустановить зависимости**:
```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```

3. **Проверить версии**:
```bash
node --version  # Должно быть ≥ 18
npm --version   # Должно быть ≥ 9
```
