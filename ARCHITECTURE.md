# DEO STUDIO CRM — Архитектура проекта

## 📋 Обзор

**Стек технологий:**
| Компонент | Технология |
|-----------|-----------|
| Frontend Web | React 18 / Next.js 14+ (App Router) |
| Mobile | Flutter 3.x |
| Backend | Python 3.12 / Django 5.x + DRF |
| Database | PostgreSQL 16 |
| Cache | Redis 7 |
| File Storage | S3 (MinIO / Yandex Object Storage) |
| Auth | JWT + OAuth 2.0 |
| Notifications | Firebase Cloud Messaging |
| Containerization | Docker + Docker Compose |
| Web Server | Nginx |

## 🔄 Основные потоки данных

### Поток создания проекта
```
Клиент → Лид → Переговоры → Договор → Проект → Команда → Задачи → Работа → Сдача
```

### Поток авторизации
```
User → Login → JWT Access/Refresh → API Gateway → Django → PostgreSQL
                                              ↓
                                         Redis (cache token)
```

## 🛡️ Безопасность

| Мера | Реализация |
|------|-----------|
| HTTPS | Nginx SSL Termination |
| 2FA | TOTP (django-otp) |
| RBAC | Кастомный permission backend |
| Audit Log | django-auditlog |
| Шифрование | AES-256 для чувствительных данных |
| Rate Limiting | django-ratelimit + Nginx |
| CORS | django-cors-headers |

---

## 📊 Производительность

- **Database**: Индексы, пагинация, PgBouncer
- **Cache**: Redis (кэш запросов, сессии)
- **Static/CDN**: S3 + CDN
- **Async Tasks**: Celery + Redis
- **WebSocket**: Django Channels + Redis
- **API**: Пагинация, select_related/prefetch_related
